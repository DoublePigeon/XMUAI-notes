# 等可能概型

在这一概率类型中，我们假定所有的基本事件都有相等的优势，或权重
# 概率

我们定义等可能概型中一个时间的概率为这一事件与总事件数之比。**关于顺序，分子与分母任意一个有顺序，那么所有都要考虑顺序。一个无顺序则都没有顺序**

> *考虑“至少有……”所代表的内容是麻烦的，我们常常需要考虑其反面，也就是“都没有”

有时我们会遇到大量事件，枚举是困难的，这时我们需要列表讨论

# 分组分配问题

这一分配问题既可以按照有顺序的方式来解决，也可以按照无顺序的方式来解决，实际上我们已经在高中的排列组合里了解过这类问题

# 分球入箱问题

有 n 个人，每人都有同等的机会被分配到 N (n ⩽ N ) 间房中的任一间去，试求下列各事件的概率：（1）A = “某指定的 n 间房中各有一人”；（2）B = “恰有 n 间房各有一人”；（3）C = “某指定的一间房中恰有 m(m ⩽ n) 个人”。

> "指定"表示无需进行选择，这一“指定”不会产生分类,因为可以指定房间

# 巴拿赫问题

某数学家有两盒火柴，每盒都有 n 根．每次使用时，他任取一盒并从中抽出一根．问他发现一盒空而另一盒还有 r(0 ⩽ r ⩽ n) 根的概率是多少？
