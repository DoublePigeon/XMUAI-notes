# 集合

一定范围内讨论的对象组成的整体称为集合，其中的对象称为其元素或成员，也就是客体的聚集

## 一些固定的集合

自然数N，整数Z，有理数Q，实数R，复数C

## 集合的表示

枚举，隐式，归纳，递归指定，巴科斯范式，文氏图

### 枚举法

列出所有元素，或者列出一部分元素，其余可以从前后关系知道

e.g. $\{1,2,3,4\}, \{1,2,3,4,...,n,...\}$

### 隐式法(叙述法)

用元素的共同性质来刻画集合

e.g. $\{x|x < 5\}, \{x|x为偶数\}$

### 归纳法

归纳法首先指出某些属于集合的基本元素，然后指出由基本元素构造出新元素的方法，最后指出该集合的界限，

### 递归指定集合法

通过计算规则定义集合中元素的方法

e.g. $a_0 = 1, a_{i+1}=2a_i, 定义S=\{a_k|k\le0\}$ 

## 集合与元素的关系

元素可以属于 $\in$ 或者不属于 $\notin$ 一个集合。

在集合中，**凡是相同的元素，均认为是同一个元素**，重复的相同元素可以合并为一个，我们认为集合中的元素都是不同且无序的

### 外延性原理

当且仅当A，B有相同元素时候，$A=B$，否则 $A\neq B$

## 集合之间的关系

当一个集合A中每一个元素都是B中的元素，那么A是B的子集，B包含A，记作 $A\subseteq B$

如果在此之上，B中与有至少一个元素不在A中，也就是 $A\subseteq B, A\neq B$，那么A是B的真子集，记作 $A\subset B$

如果 $A\subseteq B, B\subseteq A$，那么 $A=B$，这条定义可以用作证明

## 特殊的集合

空集中没有元素，其绝对唯一 *(使用反证)*，是所有集合的自己 *(包括自己)*

全集用U或者E表示，表示某个固定范围内所有的对象全体，**全集是相对唯一的**

集合A中的元素个数称为其基数，记作 $|A|$，如果一个集合的基数有限则称为有限集，无限则称为无限集

如果一个集合有n个元素，则称为n元集，其含有m个元素的子集称为m元子集，n元集有 $C_n^m$ 个m元子集，共有 $2^n$ 个子集

由集合A的所有**子集组成的集合**称为其幂集，记作 $P(A)或2^A$，这种由集合构成的集合，称为集族

## 集合的运算

$A\cap B = \{x|x \in A 且 x \in b\}$，这是并运算

$A\cup B = \{x|x\in A 或x\in B\}$，这是交运算

$A-B = \{x|x\in A且x\notin B\}$，这是差运算，结果称为相对补集

$\bar A = \{x|x\notin A\}$ ，这是补运算

$A\oplus B =\{x|x\in A 且x\notin B\} \cup \{x|x\in B 且 x\notin A\}$，这是对称差运算，它取出了两个集合中独特的部分

### 集合运算的性质

$$
\begin {cases}
A\cup A = A, A\cap A = A\\
A\cup B = B\cup A, A\cap B = B\cap A\\
A\cup(B\cup C) = (A\cup B) \cup C, A\cap (B\cap C) = (A\cap B) \cap C\\
A\cup\emptyset = A, A\cap U=A\\
A\cap\emptyset = \emptyset, A\cup U = U\\
A\cap(B\cup C) = (A\cap B)\cup (A\cap C)\\
A\cup(B\cap C) = (A\cup B)\cap(A\cup C)\\
A\cap(A\cup B) = A, A\cup(A\cap B) = A\\
\bar A\cap A= \emptyset\\
\bar A\cup A=U\\
\bar{\bar A} = A\\
\bar{(A\cup B)} = \bar A\cap \bar B, \bar{(A\cap B)} = \bar A\cup \bar B
\end {cases}
$$
