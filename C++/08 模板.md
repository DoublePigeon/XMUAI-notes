有时候，我们需要实现一堆功能实际上完全一致的函数或者类，但是其中只是存在一些类型上的差异，这时候C++给出了模板，只要实现了模板，就可以轻松得到多个版本的函数或类，实际上，vector就是一个模板

模板反映了泛型的思维，一个程序实体能够对多种类型的数据进行操作或描述的特性称为类属性 *(Generics)*

# 函数模板

要定义函数模板，我们需要先写上template关键字，然后跟着由<>框起来的模板参数列表，这一列表不能为空，列表中的类型参数前必须使用关键字class或typename

模板参数列表表示在类或函数定义中用到的类型或值，当使用模板时，我们传入模板实参，绑定到模板参数上

```cpp
template <typename T， typename t>
T func(T a, t b) { //上一行没有分号，这本质是一行！
	...
}
```

实际上，设计函数参数的时候，如果定义为一个const的引用，就可以保证这个函数可以作用于不能拷贝的实参，因此更常使用
## 非类型参数

非类型参数表示一个值而非一个类型，我们通过一个特定的类型名而非关键字class或typename来指定非类型参数

在模板被实例化的时候，非类型参数接受的实参必须是常量表达式

```cpp
template <typename t, int size>
t func(t a) {
	t temp[size];
}

func<int, 10>(a);
```

## 实例化函数模板

### 隐式实例化

我们可以通过将函数模板作为普通函数使用来实例化函数模板，这时候编译器会根据我们传入实参的类型来生成对应的模板函数

```cpp
int a, b;
double c,d;
func(a, b); //生成 int func(int T, int t)
func(b,c); //生成 int func(int T, double t)
```

注意，可以这么做是因为刚刚的例子中我们给出了两个类型参数，如果只有一个类型参数，就只能对同类的实参进行实例化，而不能实例化出上面第四行那样的函数
# 显式实例化

我们也可以通过在模板后加入<>，传入模板实参来实例化函数模板，这时候实例化为什么函数完全取决于模板实参

```cpp
func<int, int>(1,2);
```

# 类模板

类模板的定义与函数模板是类似的

```cpp
template <typename T>
class A{
	private;
		T member;
	public:
		T func();
}
```

其中如果成员函数是在类外实现的，那么也需要给他写上与class**一致的template关键字**，并且，**要给作用域运算符左侧的类加上<>来实例化**

```cpp
template <typename T>
T A<T>::func() {
	...
}
```

而且，类的模板是**不能**使用分体化实现的，这会导致我们在主函数中引入的模板不包含实现，在实例化类的模板时可能会出现在编译时找不到经过实例化的具体类对应的二进制代码，导致链接失败，程序就会出错，因此需要把声明和实现放在一起
## 实例化类模板

要实例化类模板，我们**必须**显式给出模板参数

```cpp
A<int> object;
```

## 模板类中的static成员

在类中，我们知道static成员是在对象间共享的，但是，如果是通过实例化得到的模板类，那么**static成员只会在通过同样的模板参数实例化得到的对象间，也就是同种对象间共享**

```cpp
A<int> a,b; //a,b共享一个static成员
A<double> c,d; //c,d共享另一个static成员
```

# C++标准模板库STL

STL中主要有容器类模板，迭代器类模板，算法模板

## 容器类模板

顺序容器主要有可变大小数组vector，双端队列deque，双向链表list，单向链表forward_list，固定大小数组array，栈stack，队列queue，自排序队列priority_queue(头部元素总是最大)，集合set，字典map（一种数据与另一种数据的对应，有两个类型参数），专门用于存字符的类vector容器string

除非我们有很好的理由选择别的容器，否则一般使用vector是最好的

如果要包含某种容器，要先include他们

```cpp
#include <vector>
...
```
### vector操作

#### 初始化vector

vector的初始化方式与string类似，不多介绍

#### 添加元素

使用v.push_back(arg)即可向vector的尾部添加一个元素

#### vector操作

```cpp
v.empty();// 在v中无元素时返回true，否则返回false
v.size();// 返回v中元素的个数
v.capacity();// 返回v在不重新分配内存空间的情况下，c可以保存多少元素
v[n];// 返回v中第n个位置上元素的引用，从0开始数
v.at(n);// 跟v[n]有一样的作用，但是在越界的时候会抛出out_of_range异常
v1 = v2;// 用v2中元素的拷贝替代v1中的元素
v1 = {a,b,c...};// 
v.push_back(arg);//向vector的尾部添加一个元素
v.pop_back();//删除尾部的元素
v.erase(iter);//删除迭代器指向的元素
v.erase(iter1,iter2);//删除迭代器所指定范围内的元素，返回一个指向最后一个被删除的元素之后元素的迭代器，如果e本身是尾后迭代器，那么函数也返回尾后迭代器
v.clear();//清除v中的所有元素，返回void
v.insert(p, t);//在迭代器p指向的元素之前创建一个值为t的元素
swap(vector1, vector2);//交换两个vector中的元素，必须对两个相同类型的vector才能使用，速度比拷贝赋值更快
v.assign(b,e);//将v中的元素替换为迭代器b,e表示的范围[b,e)中的元素，b和e不能指向这个vector本身中的元素
v.assign(il);//将v中的元素替换为初始化列表il中的元素
v.assign(n,t);//将v中的元素替换为n个值为t的元素
```

这些操作在大多数别的容器中也可以使用，assign只能用于顺序容器

> *swap没有交换元素本身，而是交换了容器的数据结构，因此假设有一个指向vec1中第三个元素的迭代器，与vec2进行swap后会指向vec2的第三个元素；然而对array进行swap会真正地交换其元素*

> *如果vector是无顺序的，使用swap and pop技巧，可以高效地删除一个元素，将一个元素与尾部元素交换然后弹出即可*
### 迭代器模板

#### 迭代器简介

迭代器允许我么访问容器中的元素，一个迭代器范围通常由一对迭代器表示，两个迭代器分别指向同一个容器中的元素或尾元素之后的位置，称为begin和end

然而，end指向的是范围中**最后一个元素的下一个元素**，因此有可能指向一个不存在元素的地方，而非尾元素本身，因此迭代器具有左闭合区间
$$
[begin,end)
$$
可以很简单的从容器中得到这些迭代器

```cpp
auto iter1 = v.begin();
auto iter2 = v.end();
```

为了使用这些迭代器，我们需要使用容器类中的iterator成员

```cpp
vector<typename>::iterator iter;
vector<typename>::const_iterator citer;//只读的迭代器
```

这些类型名又臭又长，使用时可以直接用auto类型，此时得到的迭代器类型依赖于容器类型

##### 迭代器操作

迭代器可以++，对于普通迭代器++会使迭代器向后运动，但是对于reverse迭代器，++会使迭代器向前运动

要访问当前指向的元素，只需使用解引用符号

```cpp
auto a = *iter;
```

## 泛型算法

大多数算法定义在头文件 algorithm 中

### find(iter1, iter2, val)

这一算法会查找iter1到iter2两个迭代器的左闭区间内有没有与val的值一致的元素，

对vector使用find，如果有则返回第一个指向那个元素的迭代器，否则返回vec.cend()

### sort(iter1, iter2)

这一函数会排序iter1到iter2的左闭区间内的元素，它使用元素对应的<运算符来排序，因此是从小到大排序

### sort(iter1,iter2,method)

这一函数与上述函数差不多，但是他的排序是根据method的返回值所决定的，注意这里的method不加()，表示我们传给函数的是一个指向排序根据函数的函数对象本身，而非其返回值

method要有两个参数，参数类型与iter1，iter2所指向的内容一致，method中的逻辑如果是 a1 < a2，那么就与上面一致地是从小到大排序，是>则为从大到小排序
