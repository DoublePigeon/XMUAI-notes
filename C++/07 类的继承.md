在继承关系中，存在基类和派生类，也成为父类和子类，子类拥有父类的所有特征（除了父类的**构造函数，析构函数，赋值操作符重载函数**），并且可以拥有**新的特征**，或者可以对父类的一些特征进行**重定义**

> *friend关系是不会继承的，父类的friend不会直接成为子类的friend*

继承可以分为单继承 *(一个子类有一个直接父类)* 和多继承 *(一个子类有多个直接父类)*

派生类可以继承定义在基类中的成员，但是派生类的成员函数不一定有权访问从基类继承而来的成员。和其他使用基类的代码一样，**派生类能访问公有成员，而不能访问私有成员**。过在某些时候基类中还有这样一种成员，**基类希望它的派生类有权访问该成员，同时禁止其他用户访问。我们用受保护的（protected）访问运算符说明这样的成员**

# 定义子类

子类需要使用类派生列表 *(Class Derivation List)* 来指出他是从哪些类继承而来的，其形式为一个冒号，后面跟着用逗号分隔的父类列表，每一个父类前都可以有public, protected, private三种访问说明符中的一个，如果不写，默认为private

这三个关键字中有层级关系，private > protected > public，父类中的某个成员在子类中会选择等级更高的访问控制，注意子类是不能访问父类的private对象的，但是可以访问父类的protected对象

子类必须将其继承而来的成员函数中那些有需要覆盖的重新声明

如果我们希望对不同的成员以不同的方式继承，那么只需再写一遍

```cpp
class A {
	public:
		void f1();
}

class B: public A{
	private:
		A::f1;
}
```

对于成员函数，只需写一遍这个函数对象即可
## public 继承

通过以下方式，就可以通过public方式来继承，这种是最常用的

```cpp
class A{
}

class B:public A{
	int new_member;
	public:
		int new_function() {
		}
}
```

在父类中定义的与子类内额外定义的同名参数 *(不论参数是否同样)*，是不能直接在子类中使用的，需要用作用域运算符来访问，或者加入using声明

```cpp
class A{
	public:
		f();
}

class B:public A{
	public:
		f();
		h(){
			A::f();//使用A中的f()
			f();//使用B中的f()
		}
		g(){
			using A::f;
			f();//使用A中的f();
		}
}
```

> *如果B为A的子类，b为B类对象，那么b.f()首先尝试调用B中的f()，如果不存在再尝试调用A中的f()*

> *对于由父类的非虚函数继承得来的函数，其中的this指针仍然指向父类*
# virtual 成员函数

基类通过在其成员函数的声明语句之前加上关键字**virtual**使得该函数执行动态绑定。任何构造函数之外的非静态函数都可以是虚函数。关键字virtual只能出现在类内部的声明语句之前，而不能用于类外部的函数定义。如果基类把一个函数声明成虚函数，则该函数在派生类中隐式地也是虚函数，不过我们也可以在派生类中写上virtual关键字，不过这不是必须的

```cpp
class A{
	public;
		virtual int f();
}

class B: public A{
	public:
		int f(); //也是虚函数
}
```

如果一个函数在父类中是virtual的，那么在子类中**相同形构** *(有相同的参数，返回类型要么与父类相同，要么是父类函数的返回类型的子类)* 的同名函数就是父类的函数的覆盖 *(override)*

> *如果我们对派生类的虚函数增加override关键字，那么这就可以显式指出这是一个覆盖，此时如果这一函数没有覆盖已经存在的虚函数，例如形参写错了而导致其成为一个独立的函数，那么编译器就会报错，有利于debug*

当某个虚函数被通过**指针或者引用**调用时，会触发动态绑定，编译器产生的代码要到运行时才能确定应该调用哪个版本的函数，使用哪个版本的函数，**取决于指针或引用所指向对象的实际类型**，而非对象指针和引用的类型

> *之前我们说过继承的来的非虚函数的this指针是父类类型的，那么，如果在这个函数中调用了另一个虚函数，就会触发动态绑定*

> *要注意的是，虚函数的函数体虽然是动态绑定的，但是**默认参数**是静态绑定的，使用哪个版本的默认参数取决于当前指针或引用的静态类型*

## 纯virtual函数

我们可以指定函数体为空，这时候需要加入 =0 来指示纯虚函数

```cpp
class A{
	public:
		virtual int f()=0;
}
```

这一作用就是，如果我们需要实现很多个属于同一个抽象概念的类，那么可能我们没法在父类里给出一个很具体的实现，那么我们就可以在父类的函数里加入=0，就不必实现，直接留给子类实现，本体只给出接口，并且给子类提供框架

拥有纯虚函数的类称为抽象类
# 子类对象的初始化

子类对象的初始化是由父类和子类共同完成的，其中子类的成员由子类的构造函数初始化，父类的成员由父类的构造函数初始化

并且，子类的构造函数会在进入其函数体之前，调用父类的构造函数

> *那么，一个子类（若其中含有一个其他类成员），那么构造函数的调用顺序就是从父类的构造函数，到类成员的构造函数，再到子类自己的构造函数*

> *相似地，析构函数的调用顺序与构造函数的调用顺序是相反的*

子类的默认拷贝构造函数时会调用父类的拷贝构造函数

其自定义拷贝构造函数，如果没有显式指出，也会隐式调用父类的拷贝构造函数

不过，子类地自定义赋值操作符是不会隐式调用父类的任何重载自定义赋值操作符的

如果是多继承而非单继承，那么，在类派生列表中的顺序，决定了父类构造函数的调用顺序
# 静态类型和动态类型

当我们使用存在public继承关系的类型时，必须将一个变量或其他表达式的静态类型 *(static type)* 与该表达式表示对象的动态类型 *(dynamic type)* 区分开来。表达式的静态类型在编译时总是已知的，它是变量声明时的类型或表达式生成的类型；动态类型则是变量或表达式表示的内存中的对象的类型。动态类型直到运行时才可知。

> *子类对象属于子类，也属于父类；父类对象的指针和引用既可以指向父类，也可以指向子类*

因此，是存在子类向父类的类型转换的，这是因为子类包含了父类的部分，而父类的**引用或指针**是可以绑定在这一父类部分上的，**实际上这种类型转换只对指针或引用有效**

> *注意，反过来是不行的，不存在父类向子类的类型转换，也不预先存在对象之间的类型转换*

```cpp
class A{
}

class B:public A{
}

B obj1;
A *obj2 = &obj1; //这是可以的 !!!此时obj2具有A静态类型，B动态类型
A &obj3 = obj1;; //这也是可以的
```

并且，可以用子类对象给父类对象赋值，赋值过程中，只有子类中父类也有的成员会赋值给父类对象，其他的会被丢弃，同理**反过来不行**，这种关系是单向的

```cpp
class A{
}

class B:public A{
}

B obj1;
A obj2 = obj1;
```

# 聚集

有时候我们不希望通过继承来复用代码，我们就可以聚集，所谓聚集就是将另一个对象作为当前对象的成员对象使用，然后直接调用其函数来实现当前对象的功能

# 队列

队列 *(Queue)* 是一种特殊的线性表，其插入在一段，删除在另一端，因此是先进先出的

```text
-> ||||| ->
```

# 多继承中的名冲突

如果一个子类有多个父类，而且父类里有多个同名函数，例如f()，那么就不能直接用f()在子类中调用这一函数，而是要使用作用域运算符来指出使用哪个父类的版本

```cpp
cls1::f();
cls2::f();
```

# virtual 基类

如果通过virtual方式继承，就可以防止在多继承中，父类又拥有同一个父类，导致某一类被重复继承，例如这样

```text
	B -> 
A ->    -> D
	C ->
```

此时，virtual父类的构造函数由当前的子类调用，只需在初始值列表中加入A(args)这样的构造函数调用即可

```cpp
class B: virtual public A {
	public:
		B(args): A(args) {
		}
}
```
