# iostream

iostream是面向控制台的，我们已经简略介绍过的

其中，通过std::hex，std::oct，可以控制数字以什么进制输出

```cpp
using namespace std;

cout << hex << x << endl;
```

通过std::setprecision(n)可以设置浮点数的输出位数

```cpp
cout << setprecision(5) << x << endl;
```

cin也可以进行输入控制，例如setw(n)，会使cin从控制台读取n-1个字符，再加上一个\0

```cpp
cin >> setw(10) >> str;
```

对于一些自定义的类，我们需要重载>>和<<函数，比如下面这样

```cpp
ostream& operator<<(ostream&out, const A &a) {
	out << a.x << ',' << a.y;
	return out;
}
```

> *注意这里使用引用和const*

> *这一函数一般按照friend函数实现，不过如果我们要实现动态绑定，由于cout始终在左边，<<是由ostream对象调用的，就无法对我们的类动态绑定了，因此我们需要手动实现一个专门用于输出的非操作符重载成员函数*

# fstream

fstream头文件给出了ifstream和ofstream来对文件进行写入和写出

文件有以文本形式和二进制形式存储的分别

fstream需要手动创建

```cpp
#include <fstream>

fstream file; //创建未绑定的文件流
fstream file(s); //创建文件流并且打开名为s的文件，s可以是string，也可以是c风格字符串的头指针，打开模式取决于fstream的类型
fstream files(s, mode);//与之前的类似，但是以指定模式打开
file.open(s);//打开名为s的文件并将file与其绑定
file.close();//关闭文件
file.is_open();//返回bool值，指出与file关联的文件是否成功打开且还未关闭
```

```cpp
ifstream in(s);
ofstream out;
```

## 模式

模式的内容处于ios命名空间中，ios命名空间在std命名空间中：

- in 以读方式打开
- out 以写方式打开，会覆盖源文件
- app 每次写操作前定位到EOF，也就是追加
- ate 打开文件后立刻定位到EOF
- trunc 截断文件
- binary 以二进制方式打开

这些模式有时候不是单个使用的，要组合他们，我们使用 | 符号

```cpp
ofstream out("file1", ios::out | ios::app);
ofstream out1("file2", ios::out | ios::binary);
```

ofstream对象中有用于操作文件指针的函数

```cpp
ofstream::seekp(n);//指定绝对位置
ofstream::seekp(偏移量, 参照位置);//指定相对于某个位置的位置
ofstream::tellp();//返回指针位置
ifstream::seekg(n);
ifstream::seekg(bias,relative);
ifstream::tellg();
```

如果希望既可以写也可以读，使用fstream即可
