## 引用

使用 & 来定义，例如
```cpp
int &ref = a;
```

引用是C++新增的特性，引用就是为对象起了一个**别名**，应用会和初始值**绑定** *(bind)* 在一起，而非拷贝。引用必须初始化， 而且一旦初始化，引用就**无法再绑定到另一个对象**

一旦定义了引用，所有对这个引用的操作都是作用在**与之绑定的对象上的**，因此，用引用作为初始值，实际上是用引用绑定的对象作为初始值

引用**只能**绑定在指定类型的对象上，因此引用不能用字面值或者表达式的计算结果初始化

**引用本身不是一个对象，因此C++中不能定义引用的引用**

由于引用绑定在了原对象上，因此以引用作为形参的函数是可以改变原对象的

# 使用new创建动态变量

new可以创建单个值，创建数组，会自动计算需要分配的大小，会自动返回相应类型的指针，会**自动调用对象类（如果是类）的构造函数**，因此使用new来创建动态变量非常优雅

```cpp
int *p = new int;
int *p = new int[10];
```

> *如果在初始化p之后又让它指向别的地方，而不撤回原来的动态变量，原来的那一块内存就没有任何方法可以访问了，这样就会导致内存泄漏*

如果要释放内存，就需要

```cpp
delete p;
```

如果是数组，就需要

```cpp
delete []p;
```

注意这个中括号！

> *delete是撤销了变量本身，但是没有撤销指针，这就会制造出一个悬浮指针，如果再操作这个指针所指的内存，就会导致未定义的行为*

delete**只能撤销动态变量**，用delete来撤销动态变量，也会调用对象类（如果是类）的折构函数

# string类型

string是可变长字符序列，使用时需要包含string头文件

```cpp
#include <string>
```


定义与操作

string类型会自行初始化，不需要手动操作

```cpp
string s1;
```

其是自动为空的

字符串之间可以用等于号赋值，用字符串为字符串赋值得到字符串的副本，并且有两种一样的方式

```cpp
string s2(s1);
string s2 = s1;
//两者作用一样
```

字符串可以用字面值赋值，得到字面值的副本，同样也有

```cpp
string s2 = "val";
string s2("val");
//作用相同
```

字符串可以使用一种特殊函数赋值

```cpp
string s2(n,'c'); //用n个字符'c'给其初始化
```

## string操作

```cpp
os<<s //将s写入输出流os，返回os
is>>s //将is中读取的字符串赋给s，字符串用空白分割，返回is
getline(is,s) //从is中读取一行赋给s，返回is
//可以用while (getling(cin,line))来一直读取直到EOF
s.empty() //s是空字符串时返回true，否则额外ifalse
s.size() //返回s中字符的个数
s[n] //返回s中第n个字符的引用，从0开始数
s1+s2 //返回s1,s2连接起来的结果
s1=s2 //用s2中的字副本代替s1中的字符
s1==s2 //用于判断s1,s2中的字符串是否完全相等，并且对大小写敏感
s1!=s2
<, <=, >, >= //利用字符的字典序来比较字符串
```

可以用cin,cout来输入，输出string。输入getline函数时，我们键入的换行符会被丢弃，所以我们输出时还需要再输出一个endl

```cpp
cin >> s;
cout << s << endl;
```

string对象可以用加法相加，也可以与字符和字面量相加，但是在进行相加时，必须保证至少一个对象是string对象，注意加法是左结合的，也就是每一个小括号里都至少要有一个string对象

string.size返回的是一个string::size_type类型

使用cctype头文件，可以对string中的字符进行一些操作

```cpp
isalnum(c); //是否是字母或数字
isalpha(c); //是否是字母
iscntrl(c); //是否是控制字符
isdigit(c); //是否是数字
isgraph(c); //是否是 不是空格但可打印 的字符
islower(c); //是否是小写字母
isprint(c); //是否是可打印的
ispunct(c); //是否是标点（不是控制字符，数字，字母，可打印空白中的任意一种
isspace(c); //是否是空白，包括空格，横向制表符，纵向制表符，回车，换行符，进纸符的一种
isupper(c); //是否为大写字母
isxdigit(c); //是否为十六进制数字可能包含的字符
tolower(c); //转换为小写字母
toupper(c); //...
```

怎么遍历字符串呢，c++提供了一个类似于for ... in ...的方法

```cpp
for (auto c : str) {
//...
}
```

但是这样没法修改其中的值，如果想要修改，我们可以用引用

```cpp
for(auto &c: str) {
//...
}
```

实际上数组都可以用这种方法遍历，非常方便
