在C++语言中，我们使用类定义自己的数据类型。通过定义新的类
型来反映待解决问题中的各种概念，可以使我们更容易编写、调试和修
改程序。

> *类的基本思想是数据抽象（data abstraction）和封装（encapsulation）。数据抽象是一种依赖于接口（interface）和实现（implementation）分离的编程（以及设计）技术。类的接口包括用户  所能执行的操作；类的实现则包括类的数据成员、负责接口实现的函数体以及定义类所需的各种私有函数。封装实现了类的接口和实现的分离。封装后的类隐藏了它的实现细节，也就是说，类的用户只能使用接口而无法访问实现部分。类要想实现数据抽象和封装，需要首先定义一个抽象数据类型（abstract data type）。在抽象数据类型中，由类的设计者负责考虑类的实现过程；使用该类的程序员则只需要抽象地思考类做了什么，而无须了解类型的工作细节。*

# 类的定义

类的定义需要类名字，里面有成员数据，和成员函数（方法）

```cpp
class Class_name {
	public:
		type member;
		type member2;
		type method(args) {
			return 0;
	}
		type method1();
	private:
		Class_name(args) {
		//...
		}
		type private_number;
		type method_private(args) {
			return 0;
		}
}

type Class_name::method1(type member, type private_number) {
	//body
}
```

其中有public和private的部分，实际上也有protected，这些称为成员访问控制，决定了一个部分是否可以直接被从外部访问，还是只能由类自己访问或通过类内部的函数访问，这体现了接口的思想

> *访问控制对类内部定义的方法不做限制，方法可以访问类内部的任意函数和变量；然而在类外，实例化的对象中，只能调用public部分的函数，访问public部分的变量*

可以在类中定义方法的原型，再在外界定义其函数体，这么做的时候要在函数名字前加入作用域运算符，并且这个函数可以直接访问类中的成员

## 构造函数

数据成员不允许直接初始化，初始化只能在构造函数中进行。构造函数的任务是初始化类对象的数据成员，无论何时只要类的对象被创建，就会执行构造函数，构造函数的名字和类名相同。和其他函数不一样的是，构造函数**没有**返回类型；除此之外类似于其他的函数，构造函数也有一个（可能为空的）参数列表和一个（可能为空的）函数体

> *实际上，不定义初始化函数的时候，就会执行默认构造函数，但是这个默认的构造函数在初始化一些自定义的类型时可能会发生未定义的行为*

一个类中可以定义多个构造函数，也就是可以重载，这样就可以应对用不同个参数来初始化的情况，一个构造函数的示例如下

```cpp
Sales_data(const std::string &s, unsigned n, double p):
	bookNo(s), units_sold(n), revenue(p*n) { }
```

构造函数中，带有一个新的部分，即冒号与花括号之间的部分，这一部分称为构造函数的初始值列表，这个列表负责为新创建的对象的一个或多个数据成员赋值，其中含有成员名字，以及名字后紧跟的括号内的值，这个值会作为当前成员的初始值，不同成员通过逗号分隔。如果某个成员没有出现在初始值列表中，那么其会通过类内初始值初始化，否则被隐式地默认初始化

使用这种方法为类数据成员初始化的时候，其成员名字后面的括号里就传入所需数量的参数即可

> *初始值列表是可以无视成员的const, &(引用) 的性质为其赋值的，如果在函数体中赋值，那么就不能为const变量赋值，也不能为引用赋值。其中，引用*

> *初始化成员的次序不是由其在初始值列表中的顺序决定的，而是由其在类中定义的顺序决定的*

> *如果参数有默认值，那么就可以直接传入更少的参数，并且不用重载*

你可以注意到函数体是空的，这是因为如果我们只需要进行简单赋值，没有其他任务，就不需要函数体了，例如如果我们要从istream读入数据，并且以istream为参数，那么我么们就需要加入一些函数体了

一旦构造函数中含有参数，那么我们在实例化对象的时候就也可以加入参数了，这与python中的__init__()类似

```cpp
class A {
	public:
		int b;
		A() = default;
		A(int a): b(a){}
}

A a(3);
A a = A(3);
A a = 3;//这三个实例化的方式是一样的，尤其第三个容易看走眼！

A a[5] = {A(1), 1};//数组也是可以初始化的，如下

A *p = new A(2);//使用指针的时候初始化，就这样做
A *p = new A[20];//使用指针创建数组类的时候，就只能调用默认初始化函数了
```

如果定义初始化函数为 default ，那么就会显式地进行默认初始化

如果成员中含有类，那么就会先按类中出现的顺序执行成员自己的构造函数，再执行当前类的构造函数

### 拷贝构造函数

在使用另一个同类对象对一个对象初始化的时候，那么就会触发一个隐式的拷贝构造函数

```cpp
class A{
	public:
		A(const A &a) {...} //这个
}
```

这个函数会逐个复制成员，实现我们之前说过的等于号赋值，或者其他的用类为类初始化的效果

```cpp
A a2(a1);
A a2 = a1;
A a2 = A(a1);
//均会调用拷贝构造函数
```

如果我们把对象作为参数传入函数，或者把对象作为函数的返回值，由于我们创建了原对象的拷贝或临时对象，也会触发拷贝构造函数

```cpp
void f(A x){
	//...
	return x;
}
```

如果你想自行实现拷贝构造函数，那么只需加入

```cpp
class A {
	public:
		A(const A &a) {
			//...
		}	
}
```

如果成员中有指针，数组，那么就**必须**实现自定义构造函数，否则新对象的指针指向旧对象的指针指向的同一区域，两个对象就会互相影响，删除这两个对象时还会将同一块内存清除两次，产生危险的效果。自定义拷贝构造函数时时我们进行的操作也叫深拷贝，否则为浅拷贝

如果类中的成员含有未完全定义，或者没有定义完的数据，那么不允许成员的类型是这些类型本身，但可以是它们的引用或者指针

> *例如，不能在定义Class B的时候加入一个成员 B a，但是可以是 B *a, B &a，对于一个声明了原型但是没有实现的Class A也是同理的。这是由是否知道占据空间的大小来决定的

### 委托构造函数

委托构造函数的作用是避免写多个重复的构造函数，只需在初始化列表中指出要把初始化委托给哪个函数，并且给其传参即可

```cpp
class Person {
public:
    // 基本构造函数
    Person(const std::string& name, int age) : name(name), age(age) {
        std::cout << "Person(const std::string&, int) called" << std::endl;
    }

    // 委托构造函数，默认年龄为 0
    Person(const std::string& name) : Person(name, 0) {
        std::cout << "Person(const std::string&) called" << std::endl;
    }

    // 委托构造函数，默认姓名为空字符串和年龄为 0
    Person() : Person("", 0) {
        std::cout << "Person() called" << std::endl;
    }

    void printInfo() const {
        std::cout << "Name: " << name << ", Age: " << age << std::endl;
    }

private:
    std::string name;
    int age;
};
```

不要让两个构造函数之间互相委托，这会导致死循环
## 析构函数

析构函数 *(Destructor)* 是用于控制销毁对象的时候如何操作的，对象的生存周期结束的时候，会调用其析构函数

析构函数的名字是 ~(class name)，没有返回类型，没有参数

```cpp
class A{
	char *str;
	public:
		~A(){
		delete []str;
		//...
		}
}
```

如果成员中含有指针，那么指针所指向的内存空间不由系统分配，因此在对象销毁时不会自动清理，这时候我们需要编写析构函数来完成这部分清理

# 成员函数

## const函数

有时候，我们只希望从类中读取数据而不希望修改数据，那么我们可以声明其为const成员函数

```cpp
class A {
	public:
		void f() const {
			//...
		}
}
```

这时候，我们就不能修改成员的值了，如果我们在类外实现函数体，那么也要在其后加入const，否则报错

const函数还有一个作用，就是当类实例化为const对象的时候，我们只能调用const函数

```cpp
class A {
	public:
		void f() const {
			//...
		}
}

const A a;
a.f();//只能调用cosnt的函数
```

## static成员函数

静态成员函数只能访问静态成员，由于其只能访问静态成员，因此也没有隐藏的this指针，静态成员函数不能被声明为const的，在类外定义static成员函数无需重复static关键字

而且，不论是**显式**还是隐式的，static成员函数都不能使用this指针
# 类的静态成员

有时候，我们需要一些类与类本身相关，而不是与各自的对象保持关联，譬如现在有一个银行类，我们希望利率变化时，所有的对象的利率都一同变化，于是我们有静态成员

静态成员存在于任何对象**之外**，对所有对象都只有一个拷贝，**而且要在类外部进行初始化**，要定义静态成员，需要加入static关键字

```cpp
class A{
	static int val;
}
int A::val=0; //只能在外部初始化！
```

# 类的friend成员

类可以允许其他类或者函数访问它的非公有成员，方法是令其他类或者函数成为它的友元（friend）。如果类想把一个函数作为它的友元，只需要增加一条以friend关键字开始的函数声明语句即可

```cpp
Class A {
	friend int F(const A &a);
	private:
		int b;
}
```

friend可以为函数，类，或某类中的某成员函数，friend可以访问类内部的成员，例如我们可以

```cpp
int F(const A &a) {
	return a.b; //F()是A的friend,所以可以这么写
}
```

friend是单向的，例如

```cpp
class A{
	friend B();
}
```

那么类B可以访问类A的成员，但是A不能访问B类的成员

并且，friend是没有传递性的，我的friend的friend不是我的friend，这就是friend分封制
# 类的操作

类之间可以用 = 运算符赋值，右值的值会被逐一复制到左值内部的成员中去，注意默认情况下这仍然是浅拷贝，如果含有指针，我们就需要自行实现=操作符的重载

类可以取地址，作为函数的参数
## this指针

对于实例化的同一个类的不同对象，**其有独立的数据成员，但是其方法是不独立的**，从内存角度而言，同一个类的不同对象数据成员会占据不同的内存空间，然而其方法是储存在同一内存空间中的，那么编译器该怎么知道方法是对哪个对象使用的呢？

每个成员函数 *(除了static成员函数)* 都有一个隐式的形参this, 其类型为

```cpp
<class name>* const this
```

例如，如果我们A类中的定义方法

```cpp
void g(int i) {
 x = i;
}
```

那么其实际上是

```cpp
void g(A* const this, int i) {
	this->x = i;
}
```

然后其编译为

```cpp
a.g(1);//我们写的
A::g(&a, 1);//编译出来的
```

这样，就可以保证了同一类的对象在调用方法时，编译器知道应该对哪个对象的值进行操作
