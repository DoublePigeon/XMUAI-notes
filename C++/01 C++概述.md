```cpp
#include <iostream>
int main(){
	std::cout << "Enter two numbers" << std::endl;
	int v1 = 0, v2 = 0;
	std:cin >> v1 >> v2;
	std::cout << "The sum of" << v1 << "and" << v2 << "is" << v1+v2 << std::endl;
	return 0;
}
```

上述的是一个实例的代码。

C++保留了C的所有成分，并且加入了面向对象程序设计的成分，也就是加入了**类**这一特性

C++程序也是通过调用 *main()* 函数来运行的，这一部分和C相同，但是其中你可以看到许多不同之处

# 输入输出基本

在C++语句中没有定义IO语句，但是包含了一个全面的标准库 *(standard library)* 来提供IO机制，因此我们需要引入iostream库。iostream库包含两个基础类istream和ostream，分别表示输入流和输出流。一个流就是一个字符序列，是从IO设备读出或写入IO设备的。术语“流”（stream）想要表达的是，随着时间的推移，字符是顺序生成或消耗的

标准库包含了四个IO对象，```cin``` 用于输入，```cout``` 用于输出，```cerr 和 clog```分别用于输出警告和错误，以及日志信息

这四个对象通常会与我们的终端关联起来，**从**终端的输入流中读入，**向**输出流输出

## 输出运算符

对于输出，我们使用到了输出运算符 *(<<)* 打印，这一运算符接受两个运算对象，具有左结合性。左侧必须是ostream对象，右侧的运算对象是将要打印的值，右侧对象的值会被写入左侧的ostream对象。

这一运算符会产生结果，结果就是左侧的对象，因此

```cpp
std::cout << "Enter two numbers";
```

在运算结束后就得到

```cpp
std::cout;
```

相当于 *<<* 吃掉了右侧的对象给左侧对象用于输出，留下了左侧对象

因此

```cpp
	std::cout << "Enter two numbers" << std::endl;
```

就等价于

```cpp
	(std::cout << "Enter two numbers") << std::endl;
```

std::endl是一个叫操纵符的特殊值，作用是结束当前行并将当前行对应的缓冲区的内容刷入设备中。在有了这一个值之后，才会真正开始将输出写入输出流

## 输入运算符

输入运算符 *(>>)* 与输出运算符类似，接受一个istream对象作为左侧运算对象，一个对象作为右侧运算对象，从给定的istream读入数据并存入给定的对象中，也具有左结合性

对于连续输入变量的情况，是使用**空格符**来分隔输出的

## 使用命名空间中的名字

你可能看到许多std::，这一字段表示，我们要使用的是std命名空间中的变量名字。命名空间的存在可以帮助规避名字定义的冲突。其中 ```::``` 是**作用域运算符**，可以指出我们要使用左侧命名空间中的名字

> *看看这个 :: ，多么微小而不易觉察，只需把它换成 ;; ，就会变成一个坑，在寻找错误的时候可以加以注意*

实际上也可以不加std::就直接使用命名空间中的名字，只需要在代码开头加入这样一行

```cpp
using namespace std;
```

就可以指出我们将要使用某一命名空间中的名字

# 控制流

控制流就是if, while, for等语句，我们也只说C++中的特性

## 读入不定数量的数据

```cpp
#include <iostream>

int main(){
    int sum = 0, value = 0;
    while (std::cin >> value) {
        sum += value;
    }
    std::cout << sum << std::endl;
    return 0;
}
```

只要把std::cin放入一个while循环中，就可以达到读入不定数量数据的效果。

当将istream对象作为条件时，其效果就是检测流的状态，流未遇到错误的时候就是成功的，遇到EOF(文件结束符)，或者无效输入的时候，其状态就会变为无效，使得条件变为false

# 作用域，生存周期

## 作用域

局部变量拥有块作用域，只能在其被定义的复合语句中使用

## 生存周期

### 静态

内存空间从程序开始执行时就被分配，直到程序结束。全局变量也拥有静态生存空间

### 自动

变量的内存空间在执行到定义它们的复合语句才开始分配，在复合语句结束时回收内存。局部变量与函数的参数一般有自动生存期

### 动态

在程序中显式地用malloc这种函数分配，然后用free这种函数收回的变量q，具有动态生存期

# 类的简介

对于一个类，我们不关心它怎么实现，只关心它的行为

可以用输入运算符 **(>>)** 从对象读，用输出运算符 **(<<)** 向对象写对象，可以用赋值运算符 **(=)** 来将一个对象中的值赋给另一个对象

然而，像加法运算符 **(+)** 或者复合赋值运算符 **(+=等)** 作用在一个对象上时，其作用是由这个对象的实现定义的

类中可以有成员函数，我们也称其为方法，要取用它，我们需要对对象使用点运算符 **(如item.isbn())** 

# 模块化

对于一个大型项目，我们将要把文件分开，使得不同模块之间的内聚性最大，耦合性最小

在C++中导入模块，我们使用

```cpp
#include "module_name.h"
```

# 内联函数

有时候函数的实现非常简单，频繁调用会导致低效，我们就可以使用内联函数

```cpp
inline int max(int a, int b){
return a>b?a:b;
}
```

这时候，编译器会在这个函数被调用的时候，直接展开成语句，就不用调用函数

> *实际上"内联"有点不知所谓，inline可以很好地传达意思*
