重载的运算符是具有特殊名字的函数：它们的名字由关键字operator和其后要定义的运算符号共同组成。和其他函数一样，重载的运算符也包含返回类型、参数列表以及函数体。

# 作为成员函数重载

如果一个运算符函数是成员函数，则它的第一个（左侧）运算对象绑定到**隐式的this指针上**，因此，成员运算符函数的（显式）参数数量比运算符的运算对象总数少一个。

对于二元运算符来说，左侧运算对象传递给第一个参数，而右侧运算对象传递给第二个参
数。

除了重载的函数调用运算符operator（）之外，其他重载运算符不能含有默认实参。

```cpp
class A{
	A operator+(const A &a) {
		...
	}
}
```

> *一些运算符不能重载，包括： 

```cpp
::
.*
.
?:
sizeof
```

> *不能重载内置类型 (int, double等等) 的运算符号*

我们只能重载已有的运算符，而无权发明新的运算符号。例如，我们不能提供operator＊＊来执行幂操作

对于一个重载的运算符来说，其优先级和结合律与对应的内置运算符保持一致

然而，如果重载逻辑与，或运算符，以及逗号运算符，可能会出现问题。例如重载&&或||，那么其短路求值特性是不被保留的，两个对象总是都被求值，因此不建议重载这些运算符

对于逗号运算符，和取地址运算符，C++已经定义了其作用域类类型对象时的含义，有了内置的含义，因此不建议重载这两个运算符

> *有四个符号（+、-、*＊、&）既是一元运算符也是二元运算符，所有这些运算符都能被重载，从参数的数量我们可以推断到底定义的是哪种运算符*

一旦重载完成，我们就可以直接调用了

```cpp
class A{
	A operator+(const &A x) const{
		...
	}
	A operator*(const &A x) const;
}
A::operator*(const &A x) const {
	...
}

A a = A(), b = A();
A c = a + b, c1 = operator+(&b); //这两种调用是等价的，但是第二种纯有病
A d = A * B;
```

# 作为friend函数重载

除了作为成员函数重载，我们可以将操作符作为friend函数重载

```cpp
class A{
	friend A operator+(const &A a, const &A b);
}

A operator+(const &A a, const &A b) {
	...
}

A c(), d();
A a = c + d;
```

如果我们不只希望重载当前类和某一特定类型的对象的运算符，那么可以重载多次

如果我们希望对类A实现这种运算

```cpp
<type x> + <class A>
```

那么就必须其就必须作为friend函数来定义，否则运算符左侧的对象赋给第一个参数，而第一个参数在成员函数中是一个this指针，左侧对象就只能是那个类本身的对象

# 重载自增与自减运算符

++和--运算符都是既可以放在前面，也可以放在后面的，因此我们也要定义两个**略有不同的**重载函数

其中，前置的版本不含实参，后置的版本接受一个额外的int类型形参，这个形参通常不使用，只用于区分版本

并且前置的版本返回一个引用，于是可以连用；后置的版本返回一个临时对象，于是不能连用，因为 (a++)++ 就相当于 temp++，不论有多少个++，最终都只会得到++一次的结果

```cpp
class A{
	int value;
	public:
		A& operator++() {
			value++;
			return *this;
		}
		A operator++(int) {
			A temp = *this;
			++(*this);
			return temp;
		}
}
```

--是一样的

# 重载赋值运算符

一般情况下我们无需手动实现 = 运算符的重载，C++的编译器会默认地实现这一运算符，其行为是对逐个成员进行拷贝，因此，如果成员中有指针，就会带来浅拷贝的问题，这时候我们需要自行实现

```cpp
A& A::operator=(const A& b) {
	if (&b == this) {
		return *this;
	}//防止给自己赋值
	//删去原有成员指针指向的内存 如果是自己给自己赋值，就会删去所有的信息，之后就没法恢复了，因此才有上面的这步
	//分配一块新内存给它
	//将b内这一指针里的内容拷贝给新内存
	//对于普通成员，直接赋值
	return *this;
}
```

并且，如果A定义了一个自定义=运算符，但是B没有，且B中有成员A，那么为B使用默认赋值的时候，是不会调用A里实现了的自定义=运算符，而是会使用A的默认=运算符的，因此我们需要在B里也显式实现=运算符的

> *拷贝构造函数和赋值操作符重载函数是类似的，分别是什么时候调用的呢？在 A b = a; 中，使用前者，因为 b 是新的。在 b = a; 中，使用后者，因为已经有 b 了*

# 重载下标运算符

如果一个类表示一种容器，那么我们通常也会希望其可以通过下标运算符 ```[]``` 来访问，于是我们可以重载下标运算符函数

```cpp
type operator[](...) {
	...
}
```

譬如，在 String 类中可能有

```cpp
char& String::operator[]{int i } {

	}
	return p[i];
}
```

# 重载成员访问运算符->

->只能作为非静态成员函数重载，并且按单目运算符重载，虽然其本身为双目运算符

通过重载这个运算符，我们可以实现智能指针类，在指向一个变量之外，它还能进行额外的操作

例如我们希望在每一次->都计数，就可以有

```cpp
Class A{
	...
	public:
		type f();
}

Class Smart_ptr{
	A* p_a;
	int count;
	public:
		B(A *p):count(0), p_a(p) {};
		A* operator->() {
			count++;
			return p_a;
		}
}

b->f();
b.operator->()->f();//上面一行就等价于这一行
```

这样我们既可以像指针一样使用类B，又可以进行计数操作，这就是一个最简单的智能指针

# 重载类型转换操作符

这一函数可以负责将类转换为其他类型，其形式如下
```cpp
operator type() const{
	...
	return ...;
}
```

可以看到，这里不写返回值类型，因为返回值类型是固定为所转换的类型的，并且其一般不应该改变对象本身的内容，因此一般定义为const函数

一般是不会定义很多类型转换函数的，不过对于类来说，定义向bool的类型转换还是比较普遍的现象。

> *类型转换函数不能将void类型作为转换目标！*

带一个参数的构造函数有时候会在运算时触发隐式的类型转换，我们这里讨论显式形式，
譬如我们有

```cpp
A::A(int x);
A& A::operator+(const &A, const&B);
```

这两个函数，那么在

```cpp
A b;
int c;
A a = b + c;
```

就会触发隐式的类型转换，将int c调用A(c)后升为A类型的对象，如果我们不希望编译器这么做，就可以增加关键词explicit

```cpp
explicit A::A(int x);
```

这样一来就不会使这个构造函数作为隐式的类型转换函数使用了，这可以避免二义性
