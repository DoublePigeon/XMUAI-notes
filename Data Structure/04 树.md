树就是一种存在朝一个方向的一对多，另一个方向则只有一对一的数据类型

树的定义是有n个结点的有限集。在任意非空树种，有且仅有一个特定的**根**结点。当 $n>1$ 时，其余的结点可以分为m个互不相交的有限集，这每个有限集都是另一颗树，称为子树

结点包含一个数据元素，以及若干指向其子树的分支

结点具有度 *(degree)*，表示其拥有的子树数量。度为0的结点称为叶，或者终端结点。度不为0的结点称为分支结点，或者非终端结点，非根结点的分支结点称为内部节点。树的度就是树内各个节点的度的最大值

> *这与离散数学中的度的定义不同，应当注意*

结点的**子树的根**称为这一结点的孩子 *(child)*，这一结点称为其child的双亲 *(parent)*

拥有同一parent的结点称为兄弟 *(sibling)*

从根到某一结点所经分支上的所有结点称为其祖先

以某一结点为根的子树种的任一结点称为其子孙

树具有层次 *(level)*，从根结点为第一层，其child为第二层，以此类推

树具有深度，也就是树中结点的最大层次数

如果两个结点的parent在同一层但是不同，那么其称为堂兄弟

如果树中的结点具有次序，不能互换，就是有序树，否则为无序树

森林就是m个互不相交的树的集合

每个结点的子树的集合称为这一结点的子树森林

任何一棵树是一个二元组 $(root, Forest)$，root是数据元素，Forest是子树森林，root与Forest中的任意元素 $T_i=(r_i,F_i)$ 存在关系 $<root,r_i>$ *(见离散数学)*

# 二叉树

二叉树就是每个结点最多有两个子树的树，分别为左子树和右子树，这两个子树均可为空。由于区分左右子树，二叉树是一种有序的树

```mermaid
graph TD
    %% 二叉树
    A((A)) -->|左| B((B))
    A -->|右| C((C))
    
    B -->|左| D((D))
    B -->|右| E((E))
    
    C -->|右| F((F))
    
    E -->|左| G((G))
````

二叉树的插入较为特殊，对于一个结点，插入会使得其一个子树变为插入的子树，被移除的那个子树又会变成插入子树的右子树，因此要求插入子树的右子树为空

二叉树的第i层最多有 $2^{i-1}$ 个结点。层数 *(高度)* 为k的二叉树总共最多有 $2^k-1$ 个结点

二叉树上，叶总是比度为2的结点多1个
## 满二叉树

## 完全二叉树

对一棵具有 $n$ 个节点的二叉树按层序编号，如果编号为 $i (1 \le i \le n)$ 的节点与**满二叉树**中编号为 $i$ 的节点在树中的位置完全相同，则为完全二叉树。

也就是，除了最后一层外，其他层都是满的；并且最后一层的节点**全部紧靠左边** *(没有任何空挡)*，也就是截去了尾部一些编号的结点

```mermaid
    2 --> 5((5))
    
    3 --> 6((6))

    classDef default fill:#e8f5e9,stroke:#388e3c,stroke-width:2px;
```

有n个结点的完全二叉树的层数 *(高度)* 为
$$
h=\lfloor \log_2n\rfloor+1
$$
观察可知，完全二叉树中度为1的结点至多有一个

完全二叉树有很好的性质，对于一个编号为i的结点，其左Child的编号为2i，右Child为2i+1。如果结点非根，那么其Parent编号为 $\lfloor \frac i 2 \rfloor$ 
## 存储二叉树

二叉树可以用顺序结构存储。对于一个完全二叉树，只需将其存在的结点存储在一个大小为 $2^n-1$ 的数组中即可。编号为i的结点存储在 $mem[i-1]$ 即可。不过，这种方式会造成很多空间的浪费，并且难以实现插入等操作

通常我们可以使用二叉链表 $[lchild, data, rchild]$ 或者三叉链表 $[lchild, data, parent, rchild]$ 来存储二叉树
## 二叉树的遍历

我们用D表示根结点，L和R表示左和右子树。先序遍历的顺序是DLR，中序是LDR，后序是LRD，这三种遍历都是深度优先的遍历，并且在遍历顺序上无区别，只是在操作结点的时机上有显著区别

层序遍历就是从上到下，从左到右的逐层遍历，这些遍历都是递归的
### 先序

```cpp
void preorderTraversal(TreeNode* root) {
    if (root == nullptr) return;
    
    doSomething(root);               // 1. 操作当前节点 (根)
    preorderTraversal(root->left);   // 2. 遍历左子树
    preorderTraversal(root->right);  // 3. 遍历右子树
}
```

这种遍历方法不会先访问到底
### 中序

```cpp
void inorderTraversal(TreeNode* root) {
    if (root == nullptr) return;
    
    inorderTraversal(root->left);    // 1. 遍历左子树
    doSomething(root);               // 2. 操作当前节点 (根)
    inorderTraversal(root->right);   // 3. 遍历右子树
}
```

这种遍历方法会先访问到底
### 后序

```cpp
void postorderTraversal(TreeNode* root) {
    if (root == nullptr) return;
    
    postorderTraversal(root->left);  // 1. 遍历左子树
    postorderTraversal(root->right); // 2. 遍历右子树
    doSomething(root);               // 3. 操作当前节点 (根)
}
```

这种遍历方法也会先访问到底
### 非递归DFS

如果树极大，那么使用递归就可能导致Stack Overflow，因此我们可以使用栈来实现前三种遍历方法
#### 非递归前序

```cpp
void dfsTraversal(TreeNode* root) {
    if (root == nullptr) return;
    
    std::stack<TreeNode*> s;
    s.push(root);
    
    while (!s.empty()) {
        TreeNode* current = s.top();
        s.pop();
        
        doSomething(current);
        
        // 【关键点】因为栈是后进先出 (LIFO)
        // 为了保证下一次先出栈的是左子节点，必须先把右子节点压入栈
        if (current->right != nullptr) {
            s.push(current->right);
        }
        if (current->left != nullptr) {
            s.push(current->left);
        }
    }
}
```
#### 非递归中序

```cpp
void inorderIterative(TreeNode* root) {
    std::stack<TreeNode*> s;
    TreeNode* curr = root;
    
    // 循环条件：当前节点不为空，或者栈不为空
    while (curr != nullptr || !s.empty()) {
        // 1. 一直向左深入，把沿途节点压栈
        while (curr != nullptr) {
            s.push(curr);
            curr = curr->left;
        }
        
        // 2. 此时 curr 为空，说明左边走到底了，从栈中弹出一个节点
        curr = s.top();
        s.pop();
        
        // 3. 操作该节点（左-根-右 中的 "根"）
        doSomething(curr);
        
        // 4. 转向右子树
        curr = curr->right;
    }
}
```

#### 非递归后序

```cpp
void postorderIterativeOneStack(TreeNode* root) {
    std::stack<TreeNode*> s;
    TreeNode* curr = root;
    TreeNode* prev = nullptr; // 记录上一个被完全处理并弹出的节点
    
    while (curr != nullptr || !s.empty()) {
        // 1. 一直向左深入，压栈
        while (curr != nullptr) {
            s.push(curr);
            curr = curr->left;
        }
        
        // 2. 查看栈顶元素（注意：这里只是 peek，先不 pop）
        curr = s.top();
        
        // 3. 判断是否可以处理当前节点
        // 条件：右子树为空，或者右子树刚刚被处理过 (curr->right == prev)
        if (curr->right == nullptr || curr->right == prev) {
            s.pop();             // 真正出栈
            doSomething(curr);   // 操作节点
            prev = curr;         // 记录当前节点为刚刚处理过的节点
            curr = nullptr;      // 【关键步】置空 curr，强制下一轮直接从栈里取元素，而不是重新压栈
        } else {
            // 4. 否则，说明右子树还没处理，转向右子树
            curr = curr->right;
        }
    }
}
```

### 广度优先搜索 *(BFS)*

广度优先搜索是从上到下，从左到右的遍历，可以使用队列实现

```cpp
void bfsTraversal(TreeNode* root) {
    if (root == nullptr) return;
    
    std::queue<TreeNode*> q;
    q.push(root);
    
    while (!q.empty()) {
        TreeNode* current = q.front();
        q.pop();
        
        doSomething(current);
        
        // 先将左子节点入队，再将右子节点入队
        if (current->left != nullptr) {
            q.push(current->left);
        }
        if (current->right != nullptr) {
            q.push(current->right);
        }
    }
}
```
# 树

树的存储既要存储数据，也要存储与别的元素的关系
## parent表示法

每个结点，除了根，都只有一个parent，因此可以按照 $[data,parent]$ 的方式存储

这种方法有利于查找任何结点的parent和祖先，但是难以查找孩子和兄弟，也没有表示出结点之间的先后次序
## child表示法

使用多重链表，每个结点有多个指针域，指向各个子树的root，子树的指针可以存储在链表中
$$
[data,childsList]
$$
或者存储在别的顺序存储方式中
$$
[data,childsVector]
$$
这样子，就可以方便地查找孩子和子孙，有利于看出先后次序，但是难以查找parent和祖先，也较难以查找结点的兄弟
## child-parent表示法

只需结合上述两种方法，就可以得到不错的表示方法了
$$
[data,parent,childsVector]
$$
## child-sibling表示法

在这种结构中，我们使用二叉链表，存储指向第一个孩子和下一个兄弟的指针
$$
[data,firstChild,nextSibling]
$$
这种方法有利于查找子孙和兄弟结点，但是难以查找祖先和parent
### 树与二叉树的转换

这种存储方法对应了树向二叉树转换的规则，即：

1. 二叉树的**根结点**就是原树的根结点
    
2. 二叉树的**左指针**指向原树的**第一个孩子**
    
3. 二叉树的**右指针**指向原树的**下一个兄弟**

反之，如果二叉树要转换为树，那么：

1. 树的根结点就是原二叉树的根结点
    
2. 树的**第一个孩子**就是原二叉树的左孩子
    
3. 树的**下一个兄弟**就是原二叉树的右孩子
## 森林转换为二叉树

首先，先把各个树单独转换为多个二叉树A,B,C,D

然后，A，B，C，D本来也是树的根，因此没有兄弟，所以这些二叉树的右子树为空，于是第一个二叉树A就是目标二叉树的根，其左子树就是A，右子树是B，然后B的右子树是C，以此类推

递归地说，目标二叉树的根是A，右子树是 $[B,C,D]$ 合成的整个二叉树，以此类推

如果要将二叉树转换为森林，那么就先拆分，根节点及其左子树是A，然后走到根节点的右子树，其本身以及其左子树是B，以此类推
## 树的先序遍历

先访问根节点，然后从左到右访问其子树
## 树的后序遍历

先从左到右访问其子树，再访问根节点
## 森林的先序遍历

先先序遍历第一棵树，再遍历除了第一棵树之外的森林
$$
1root\to1子树森林\to 其他森林
$$
## 森林的中序遍历

先后序遍历第一棵树，再遍历除了第一棵树之外的森林
$$
1子树森林\to1root\to其他森林
$$
# 赫夫曼树

赫夫曼树又称为最优二叉树。其每一个结点带有一个权值 $w_i$。每个结点的路径长度就是从根结点走到这一结点经过边的数量 $l_i$

那么，结点的带权路径长度就定义为 $w_i l_i$

树的带权路径长度 *(WPL)* 是树所有**叶子**结点的带权路径长度之和
$$
\sum w_il_i
$$
**赫夫曼树的定义就是**，在给定一组具有确定权值的叶子节点的各种二叉树中，**WPL（树的带权路径长度）最小**的那棵二叉树，就是赫夫曼树
## 构造赫夫曼树

构造赫夫曼树的过程是一个经典的**贪心算法**，核心思想是每次挑最小的两个

首先我们拿到给定的一堆带权结点，将其看作一个每个树只有一个节点的森林

然后，取根权值最小的两个结点，生成一个父结点的权值是这二者的权之和，并且左右孩子分别为这两个最小权值的结点。之后在森林中去除取出的这两个结点，将新得到的父结点加入

不断重复，直到只剩下一棵树即构造完成

> *在C++中实现构造哈夫曼树，可以使用优先队列priority_queue，其永远保证队首的是最小元素*

赫夫曼树的性质有：
- 没有度为1的结点，因为这会无端地提高WPL
- 结点数固定，如果有n个叶，那么构造时会产生n-1个父节点，于是总结点个数就是2n-1
- 如果有权值相同的结点，那么树的形式可能不同，但是WPL一样
### 赫夫曼树

*(AIGC)* 赫夫曼树最著名的应用是**数据压缩**，即**赫夫曼编码（Huffman Coding）**。

在计算机中存储或传输文本时，如果每个字符都用相同长度的二进制位（如 ASCII 码均用 8 位）表示，会很占空间。  
利用赫夫曼树，我们可以实现**可变长编码**：

- **做法：** 把文本中字符出现的频率作为“权值”构造赫夫曼树。规定树的左分支代表 0，右分支代表 1。从根节点走到每个叶子节点（字符）的路径，就是该字符的编码。
    
- **优势1（压缩）：** 出现频率高的字符（权值大）离根近，编码短；频率低的字符编码长。整体算下来，文件的总长度（其实就是 WPL）最小，实现了极高的数据压缩率。
    
- **优势2（无歧义）：** 因为所有的字符都只在**叶子节点**上，所以任何一个字符的编码都不可能是另一个字符编码的**前缀**（这叫**前缀码**）。解码时绝对不会产生歧义。


> *前缀编码：每一个字符对应的编码都不可能是另一个字符的前缀*
#### 赫夫曼编码的存储

只需存储对应的指针即可
#### 逆向求解赫夫曼编码

从叶开始遍历，如果当前结点是其双亲的左或右孩子，初始编码为一个空字符串，那么就push_front一个0或1

或者也可以正向遍历
# 线索二叉树

在遍历二叉树时，会产生一个遍历序列。我们定义，前驱和后继就是指在这一序列中，某一个结点在**序列中**的前一个结点和后一个结点

线索二叉树是一种物理结构

线索就是指指向前驱或者后继结点的指针，加上线索的二叉树就是线索二叉树

二叉树中有n个结点，就会有n+1个空指针，因此可以用空指针来存储前驱和后继，并且给指针加上标签，来指示其指示的是孩子还是前驱或者后继，比如0表示孩子，1表示前驱或者后继
$$
[data,<LTag, Lchild>,<RTag,Rchild>]
$$
并且，我们额外规定一个头结点，规定其是遍历序列的第一个结点的前驱，是遍历序列最后一个结点的后继，其左指针指向左孩子，也就是二叉树的根root，右指针指向其后继，为遍历序列的最后一个结点

这个时候，要查找前驱或者后继，如果一个结点的相应指针是1类型的，那么就是那个指针所指结点，如果不是，那么就要按照规定的遍历顺序真正走一遍才能找到 *(e.g. 中序遍历序列的某个结点的后继是其右子树的最左下角的元素)*
## 线索二叉树的遍历

对于中序遍历，我们先找到起点，然后不断寻找后继即可

```cpp
void inOrderTraversal(ThreadNode* root) {
    if (root == nullptr) return;

    ThreadNode* p = root;

    // 1. 寻找中序遍历的第一个结点（最左下角的结点）
    while (p->ltag == 0) {
        p = p->left;
    }

    // 开始遍历
    while (p != nullptr) {
        // 访问当前结点
        doSomething(p);

        // 2. 查找后继结点
        if (p->rtag == 1) {
            // 情况 A：如果右指针是线索，直接指向后继结点
            p = p->right;
        } else {
            // 情况 B：如果右指针是孩子，后继结点是其右子树中最左侧的结点
            p = p->right;
            while (p != nullptr && p->ltag == 0) {
                p = p->left;
            }
        }
    }
}
```
## 线索化二叉树

以中序为例，要线索化一个二叉树，我们引入一个全局的指针pre，记录刚刚访问过的上一个结点，初始时pre是头结点。

在中序遍历的过程中，对于正在访问的结点p，如果其没有左孩子，那么其前驱是pre，并且pre的后继就是p，之后令pre与p同步一次，递归完成即可

```cpp
// 注意：pre 必须按引用传递（或者使用全局变量），保证在整个递归过程中共享同一个 pre
void inOrderThreadingHelper(ThreadNode* p, ThreadNode*& pre) {
    if (p == nullptr) {
        return;
    }

    // 1. 递归线索化左子树
    inOrderThreadingHelper(p->left, pre);

    // ---------------- 处理当前结点 p ----------------

    // 2. 处理当前结点的前驱线索
    if (p->left == nullptr) {
        p->left = pre;
        p->ltag = 1;
    }

    // 3. 处理前驱结点的后继线索
    if (pre != nullptr && pre->right == nullptr) {
        pre->right = p;
        pre->rtag = 1;
    }

    // 4. pre 紧跟 p 的步伐，移动到当前结点
    pre = p;

    // ------------------------------------------------

    // 5. 递归线索化右子树
    inOrderThreadingHelper(p->right, pre);
}

//初始化和收尾
void createInOrderThreadTree(ThreadNode* root) {
    if (root == nullptr) return;

	ThreadNode* head = TreeNode(0)
    ThreadNode* pre = head; // 初始化 pre 为head
    pre->left = root;
    pre->rtag = 1;

    // 调用核心线索化函数
    inOrderThreadingHelper(root, pre);

    // 【重要收尾】：处理遍历的最后一个结点
    // 遍历结束后，pre 指向中序遍历的最后一个结点。它的右指针一定为空，需要将其设为线索
    if (pre->right == nullptr) {
        pre->rtag = 1;
        pre->right = head;
        head->right = pre;
        // pre->right 保持为 nullptr 即可，表示遍历结束
    }
}
```
