# 度量衡

我们定义，如果存在正常数 $c$ 和 $n_0$，使得 $N>n_0$ 时，$T(N)\le cf(N)$，那么我们就记 $T(N)=O(f(N))$

如果存在正常数 $c$ 和 $n_0$，使得 $N>n_0$ 时，$T(N)\ge cf(N)$，那么我们就记 $T(N)=\Omega(f(N))$

这两个记号可以用于衡量算法的性能，在分析算法时，我们将所处理问题的规模记作 $n$
# 时间复杂度分析

为了简化分析，我们约定不存在特定的时间单元，而是使用一个基本程序操作作为时间单元。我们用 $T(n) = O(f(n))$ 来衡量

作为例子，以下是一个用来计算 $\sum i^3$ 的算法

```cpp
int Sum(int N) {
	int i, PartialSum;
	
	PartialSum = 0; //1
	for(i = 0; i <= N; ++i) { //2
		PartialSum += i*i*i; //3
	}
	return PartialSum; //4
}
```

在这个例子中，每次调用函数，都会调用一次1和4，会调用N次2 *(自增)* 和3，因此总共花费 $2N+2$ 个时间单元

之后，我们在衡量复杂度时只保留最高次数项，去除其系数，因此这个算法的时间复杂度是 $O(N)$ 的

> *由此易得，O(f)+O(g)=max(O(f), O(g))=O(f+g), O(f)xO(g)=O(fg)

> *常见的复杂度有 $O(\log N) < O(N)<O(N\log N)<O(N^2)<O(N^3)<O(2^N)$* 在实际问题中，认为多项式复杂度的问题都是易解的，指数级复杂度的问题是难解的

# 空间复杂度分析

空间复杂度使用与时间复杂度相同的度量衡，其用来衡量算法所需的存储空间，同样地，我们使用空间单元来衡量空间大小，记作 $S(N) = O(f(n))$

对于一个算法，我们需要考虑：
- 算法本身占有的存储空间，如指令，常数，变量
- 输入与输出所占用的存储空间
- 算法运行过程中临时占用的辅助存储空间

在实际运用中，我们通常考虑第三部分的空间

```cpp
for (int i = 0; i < n; ++i) {
	int t = a[i];
	a[i] = a[n-i-1];
	a[n-i-1] = t
}
```

在上例中，不论何时都只有1个辅助变量占有空间，因此其 $S(N) = O(1)$
