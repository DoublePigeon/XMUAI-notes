图是一种更加复杂的数据结构，图中的任意两个元素都可能相关

图的定义和代数性质已经在离散数学的部分中给出，我们只讲解对于数据结构来说独特的部分。在数据结构中我们先不讨论多重图和自环

稀疏图和稠密图分别指边很少或者边很多的图

有权图称为网格
# 生成树

生成树也叫极小连通子图。生成树是一个图的生成子图，并且其中恰好没有简单回路。

向生成树中添加一条边，必定会形成简单回路

对于有n个顶点的图，若其边小于n-1条，说明其为非连通图；若其边大于n-1条，则一定有简单回路

一个图可能有多种生成树，生成树的边数必然为n-1
# 有向树

如果一个有向图恰有一个顶点入度为0，其余顶点入度均为1，就称为有向树
## 有向图的生成森林

由若干有向树组成，并且包含图中全部顶点，但是只有足以构成若干棵不相交的有向树的边
# 图的存储
## 数组表示法

可以使用两个数组来存储图的信息。一个数组表示所有顶点，另一个数组表示图的邻接矩阵

显然无向图的邻接矩阵是对称的，有向图的不一定对称

如果图为网格，也就是边含有权值，那么邻接矩阵中不存储1和0，而是存储边对应的权值，不存在的边规定为无穷

这种方式的存储利于实现图的操作。但是占据 $O(n^2)$ 的数据单元，并且读入数据有 $O(n^2)$ 的时间复杂度
## 邻接表法

邻接表有一个顶点表，记录顶点的信息，然后有一个邻接链表，其为每个顶点建立一个单链表，表示依附于这一顶点 *(始点或终点为这一顶点)* 的所有边，如果图是有向图，那么就只表示以这一顶点为始点的所有边
$$
EdgeList:[EdgeData,nextEdge], Vector<(VexData, FirstEdge:EdgeList)>
$$
这种方法只占据 $O(n)$ 的数据单元，但是不利于判断顶点的入度
## 十字链表法

这本质是结合了邻接表和逆邻接表，用于存储有向图

在这种方式中，每个顶点都对应一个顶点结点，并且各对应两条单链表，分别对应以该结点为始点和终点的所有边
$$
[data,InEdgeList,OutEdgeList]
$$
并且，显然每个边与两个结点连接，指向第一个结点和对于第一个结点的边表的下一个边，第二个结点和对于第二个结点的边表的下一个边
$$
[info, ivex,ilink,jvex,jnext]
$$
## 邻接多重表

这是一种无向图的链式存储结构

每个顶点对应一个顶点结点，建立一条单链表，串联所有依附于该顶点的边
$$
Vertex:[data,firstEdge]
$$
每个边对应一个边结点，这个边结点可以同时挂靠在两个顶点的链表上，用mark标记是否被访问过，用于遍历，然后分别存储依附的第一个顶点以及在第一个顶点的链表中对应的下一条边，和在第二个顶点和在这一顶点的边链表中对应的下一个边，以及额外的信息
$$
Edge:[mark,ivex,ilink,jvex,jlink,info]
$$
多重链表可以防止边的重复存储，节省了一定空间
# 图的遍历

图的遍历比树复杂，并且要求每个顶点都被遍历。因此我们要给顶点赋予一个标记 $mark$，表示其是否被遍历过
## DFS遍历

这种遍历方式从某个顶点v出发，依次遍历v的未被访问邻接点，直到图中所有与v连通的结点都被遍历

如果还有没有被遍历的结点，从这个结点出发再开始遍历，类似于树的先序遍历 *(二叉树的中序遍历)* 

其可以递归实现，也可以用栈实现。采用邻接矩阵时具有时间复杂度 $O(n^2)$，采用邻接表时为 $O(n+e)$
## BFS遍历

这类似于树的BFS。从某个顶点V出发，先操作节点中的数据，然后依次遍历其未被访问的邻接点，直到所有结点都被访问

如果还有未被访问的结点，就再从这个结点开始重复这一过程

其可以用队列实现
# 图的连通性

任意两个结点之间都连通的称为连通图，图的连通的子图称为连通分量

如果一个图最少可以分为n个连通图，这些图就称为图的强连通分量

要寻找图的连通分量，只需对图进行DFS或者BFS，然后记录运行了几次 *(也就是由于还有没有遍历的结点导致要再次遍历)* 即可

要生成连通图的生成树，只需对图进行DFS或者BFS遍历，遍历顺序就可以构成生成树了，也就是，如果当前结点的一个邻接点**未被遍历**，就遍历它并且在树中将其与当前结点连接 。如果不是连通图，也可以用这种方式得到生成森林
## 关节点

如果删去某个顶点可以使得图的一个连通分量变成两个或者以上个连通分量，那么这个顶点就称为图的一个关节点
## 重连通图

重连通图是一个没有关节点的连通图，其任意一对顶点之间至少存在两条路劲，删去任何一个顶点不会破坏图的连通性

如果一个连通图至少删去k个顶点才能破坏图的连通性，就称图的连通度为k
## 求最小生成树

最小生成树何其对应的Kruskal和Prim算法的思想已经在离散数学的部分中介绍，我们只给出其程序实现，第一个的复杂度为 $O(E\log E)$，第二个为 $O(E\log V)$

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>

using namespace std;

// ==========================================
// 1. Kruskal算法所需的数据结构
// ==========================================

// 定义边结构体
struct Edge {
    int u, v, weight;
    // 重载小于号，用于按权值对边进行排序
    bool operator<(const Edge& other) const {
        return weight < other.weight;
    }
};

// 并查集（用于Kruskal算法中检测环）
class DSU {
private:
    vector<int> parent;
    vector<int> rank;
public:
    DSU(int n) {
        parent.resize(n);
        rank.resize(n, 0);
        for (int i = 0; i < n; i++) {
            parent[i] = i; // 初始时每个节点的父节点是自己
        }
    }

    // 查找根节点（带路径压缩）
    int find(int i) {
        if (parent[i] == i)
            return i;
        return parent[i] = find(parent[i]);
    }

    // 合并两个集合（按秩合并）
    bool unite(int i, int j) {
        int root_i = find(i);
        int root_j = find(j);
        
        if (root_i != root_j) {
            if (rank[root_i] < rank[root_j]) {
                parent[root_i] = root_j;
            } else if (rank[root_i] > rank[root_j]) {
                parent[root_j] = root_i;
            } else {
                parent[root_j] = root_i;
                rank[root_i]++;
            }
            return true; // 成功合并，说明没有环
        }
        return false; // 在同一个集合中，说明产生了环
    }
};

// Kruskal算法实现
void Kruskal(int V, vector<Edge>& edges) {
    int mst_weight = 0;
    vector<Edge> mst_edges;
    
    // 1. 将所有边按权值从小到大排序
    sort(edges.begin(), edges.end());
    
    DSU dsu(V);
    
    // 2. 遍历排序后的边
    for (const auto& edge : edges) {
        // 如果当前边的两个顶点不在同一个集合中（即加入后不会形成环）
        if (dsu.unite(edge.u, edge.v)) {
            mst_weight += edge.weight;
            mst_edges.push_back(edge);
        }
        // 如果已经找到了 V-1 条边，MST已经构建完成
        if (mst_edges.size() == V - 1) break;
    }
    
    // 打印结果
    cout << "--- Kruskal 算法结果 ---" << endl;
    for (const auto& e : mst_edges) {
        cout << "边: " << e.u << " - " << e.v << " \t权值: " << e.weight << endl;
    }
    cout << "最小生成树总权值: " << mst_weight << "\n\n";
}


// ==========================================
// 2. Prim算法实现
// ==========================================

// Prim算法实现
// 参数：V为顶点数，adj为邻接表 (格式: adj[u] = {{v, weight}, ...})
void Prim(int V, const vector<vector<pair<int, int>>>& adj) {
    int mst_weight = 0;
    
    // 优先队列，存储格式为 {weight, {u, v}}，使用greater实现最小堆
    typedef pair<int, pair<int, int>> piii;
    priority_queue<piii, vector<piii>, greater<piii>> pq;
    
    // 记录节点是否已经加入到MST中
    vector<bool> inMST(V, false);
    
    vector<pair<int, int>> mst_edges; // 记录MST的边用于打印 {u, v}
    
    // 从顶点 0 开始
    inMST[0] = true;
    for (const auto& neighbor : adj[0]) {
        int v = neighbor.first;
        int weight = neighbor.second;
        pq.push({weight, {0, v}}); // 压入与0相连的边
    }
    
    while (!pq.empty() && mst_edges.size() < V - 1) {
        int weight = pq.top().first;
        int u = pq.top().second.first;
        int v = pq.top().second.second;
        pq.pop();
        
        // 如果终点 v 已经在 MST 中，则跳过（避免环）
        if (inMST[v]) continue;
        
        // 将 v 加入 MST
        inMST[v] = true;
        mst_weight += weight;
        mst_edges.push_back({u, v});
        
        // 遍历 v 的所有邻接点，将连接到未加入MST节点的边压入优先队列
        for (const auto& neighbor : adj[v]) {
            int next_v = neighbor.first;
            int next_weight = neighbor.second;
            if (!inMST[next_v]) {
                pq.push({next_weight, {v, next_v}});
            }
        }
    }
    
    // 打印结果
    cout << "--- Prim 算法结果 ---" << endl;
    // 顺便找回一下各边的权值用于打印
    for (const auto& e : mst_edges) {
        int u = e.first, v = e.second;
        int w = 0;
        for (auto& neighbor : adj[u]) {
            if (neighbor.first == v) { w = neighbor.second; break; }
        }
        cout << "边: " << u << " - " << v << " \t权值: " << w << endl;
    }
    cout << "最小生成树总权值: " << mst_weight << endl;
}
```
