图是一种更加复杂的数据结构，图中的任意两个元素都可能相关

图的定义和代数性质已经在离散数学的部分中给出，我们只讲解对于数据结构来说独特的部分。在数据结构中我们先不讨论多重图和自环

稀疏图和稠密图分别指边很少或者边很多的图

有权图称为网格
# 生成树

生成树也叫极小连通子图。生成树是一个图的生成子图，并且其中恰好没有简单回路。

向生成树中添加一条边，必定会形成简单回路

对于有n个顶点的图，若其边小于n-1条，说明其为非连通图；若其边大于n-1条，则一定有简单回路

一个图可能有多种生成树，生成树的边数必然为n-1
# 有向树

如果一个有向图恰有一个顶点入度为0，其余顶点入度均为1，就称为有向树
## 有向图的生成森林

由若干有向树组成，并且包含图中全部顶点，但是只有足以构成若干棵不相交的有向树的边
# 图的存储
## 数组表示法

可以使用两个数组来存储图的信息。一个数组表示所有顶点，另一个数组表示图的邻接矩阵

显然无向图的邻接矩阵是对称的，有向图的不一定对称

如果图为网格，也就是边含有权值，那么邻接矩阵中不存储1和0，而是存储边对应的权值，不存在的边规定为无穷

这种方式的存储利于实现图的操作。但是占据 $O(n^2)$ 的数据单元，并且读入数据有 $O(n^2)$ 的时间复杂度
## 邻接表法

邻接表有一个顶点表，记录顶点的信息，然后有一个邻接链表，其为每个顶点建立一个单链表，表示依附于这一顶点 *(始点或终点为这一顶点)* 的所有边，如果图是有向图，那么就只表示以这一顶点为始点的所有边
$$
EdgeList:[EdgeData,nextEdge], Vector<(VexData, FirstEdge:EdgeList)>
$$
这种方法只占据 $O(n)$ 的数据单元，但是不利于判断顶点的入度
## 十字链表法

这本质是结合了邻接表和逆邻接表，用于存储有向图

在这种方式中，每个顶点都对应一个顶点结点，并且各对应两条单链表，分别对应以该结点为始点和终点的所有边
$$
[data,InEdgeList,OutEdgeList]
$$
并且，显然每个边与两个结点连接，指向第一个结点和对于第一个结点的边表的下一个边，第二个结点和对于第二个结点的边表的下一个边
$$
[info, ivex,ilink,jvex,jnext]
$$
## 邻接多重表

这是一种无向图的链式存储结构

每个顶点对应一个顶点结点，建立一条单链表，串联所有依附于该顶点的边
$$
Vertex:[data,firstEdge]
$$
每个边对应一个边结点，这个边结点可以同时挂靠在两个顶点的链表上，用mark标记是否被访问过，用于遍历，然后分别存储依附的第一个顶点以及在第一个顶点的链表中对应的下一条边，和在第二个顶点和在这一顶点的边链表中对应的下一个边，以及额外的信息
$$
Edge:[mark,ivex,ilink,jvex,jlink,info]
$$
多重链表可以防止边的重复存储，节省了一定空间
# 图的遍历

图的遍历比树复杂，并且要求每个顶点都被遍历。因此我们要给顶点赋予一个标记 $mark$，表示其是否被遍历过
## DFS遍历

这种遍历方式从某个顶点v出发，依次遍历v的未被访问邻接点，直到图中所有与v连通的结点都被遍历

如果还有没有被遍历的结点，从这个结点出发再开始遍历，类似于树的先序遍历 *(二叉树的中序遍历)* 

其可以递归实现，也可以用栈实现。采用邻接矩阵时具有时间复杂度 $O(n^2)$，采用邻接表时为 $O(n+e)$
## BFS遍历

这类似于树的BFS。从某个顶点V出发，先操作节点中的数据，然后依次遍历其未被访问的邻接点，直到所有结点都被访问

如果还有未被访问的结点，就再从这个结点开始重复这一过程

其可以用队列实现
# 图的连通性

任意两个结点之间都连通的称为连通图，图的连通的子图称为连通分量

如果一个图最少可以分为n个连通图，这些图就称为图的强连通分量

要寻找图的连通分量，只需对图进行DFS或者BFS，然后记录运行了几次 *(也就是由于还有没有遍历的结点导致要再次遍历)* 即可

要生成连通图的生成树，只需对图进行DFS或者BFS遍历，遍历顺序就可以构成生成树了，也就是，如果当前结点的一个邻接点**未被遍历**，就遍历它并且在树中将其与当前结点连接 。如果不是连通图，也可以用这种方式得到生成森林
## 关节点

如果删去某个顶点可以使得图的一个连通分量变成两个或者以上个连通分量，那么这个顶点就称为图的一个关节点
## 重连通图

重连通图是一个没有关节点的连通图，其任意一对顶点之间至少存在两条路劲，删去任何一个顶点不会破坏图的连通性

如果一个连通图至少删去k个顶点才能破坏图的连通性，就称图的连通度为k
## 求最小生成树

最小生成树何其对应的Kruskal和Prim算法的思想已经在离散数学的部分中介绍，我们只给出其程序实现，第一个的复杂度为 $O(E\log E)$，第二个为 $O(E\log V)$

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>

using namespace std;

// ==========================================
// 1. Kruskal算法所需的数据结构
// ==========================================

// 定义边结构体
struct Edge {
    int u, v, weight;
    // 重载小于号，用于按权值对边进行排序
    bool operator<(const Edge& other) const {
        return weight < other.weight;
    }
};

// 并查集（用于Kruskal算法中检测环）
class DSU {
private:
    vector<int> parent;
    vector<int> rank;
public:
    DSU(int n) {
        parent.resize(n);
        rank.resize(n, 0);
        for (int i = 0; i < n; i++) {
            parent[i] = i; // 初始时每个节点的父节点是自己
        }
    }

    // 查找根节点（带路径压缩）
    int find(int i) {
        if (parent[i] == i)
            return i;
        return parent[i] = find(parent[i]);
    }

    // 合并两个集合（按秩合并）
    bool unite(int i, int j) {
        int root_i = find(i);
        int root_j = find(j);
        
        if (root_i != root_j) {
            if (rank[root_i] < rank[root_j]) {
                parent[root_i] = root_j;
            } else if (rank[root_i] > rank[root_j]) {
                parent[root_j] = root_i;
            } else {
                parent[root_j] = root_i;
                rank[root_i]++;
            }
            return true; // 成功合并，说明没有环
        }
        return false; // 在同一个集合中，说明产生了环
    }
};

// Kruskal算法实现
void Kruskal(int V, vector<Edge>& edges) {
    int mst_weight = 0;
    vector<Edge> mst_edges;
    
    // 1. 将所有边按权值从小到大排序
    sort(edges.begin(), edges.end());
    
    DSU dsu(V);
    
    // 2. 遍历排序后的边
    for (const auto& edge : edges) {
        // 如果当前边的两个顶点不在同一个集合中（即加入后不会形成环）
        if (dsu.unite(edge.u, edge.v)) {
            mst_weight += edge.weight;
            mst_edges.push_back(edge);
        }
        // 如果已经找到了 V-1 条边，MST已经构建完成
        if (mst_edges.size() == V - 1) break;
    }
    
    // 打印结果
    cout << "--- Kruskal 算法结果 ---" << endl;
    for (const auto& e : mst_edges) {
        cout << "边: " << e.u << " - " << e.v << " \t权值: " << e.weight << endl;
    }
    cout << "最小生成树总权值: " << mst_weight << "\n\n";
}


// ==========================================
// 2. Prim算法实现
// ==========================================

// Prim算法实现
// 参数：V为顶点数，adj为邻接表 (格式: adj[u] = {{v, weight}, ...})
void Prim(int V, const vector<vector<pair<int, int>>>& adj) {
    int mst_weight = 0;
    
    // 优先队列，存储格式为 {weight, {u, v}}，使用greater实现最小堆
    typedef pair<int, pair<int, int>> piii;
    priority_queue<piii, vector<piii>, greater<piii>> pq;
    
    // 记录节点是否已经加入到MST中
    vector<bool> inMST(V, false);
    
    vector<pair<int, int>> mst_edges; // 记录MST的边用于打印 {u, v}
    
    // 从顶点 0 开始
    inMST[0] = true;
    for (const auto& neighbor : adj[0]) {
        int v = neighbor.first;
        int weight = neighbor.second;
        pq.push({weight, {0, v}}); // 压入与0相连的边
    }
    
    while (!pq.empty() && mst_edges.size() < V - 1) {
        int weight = pq.top().first;
        int u = pq.top().second.first;
        int v = pq.top().second.second;
        pq.pop();
        
        // 如果终点 v 已经在 MST 中，则跳过（避免环）
        if (inMST[v]) continue;
        
        // 将 v 加入 MST
        inMST[v] = true;
        mst_weight += weight;
        mst_edges.push_back({u, v});
        
        // 遍历 v 的所有邻接点，将连接到未加入MST节点的边压入优先队列
        for (const auto& neighbor : adj[v]) {
            int next_v = neighbor.first;
            int next_weight = neighbor.second;
            if (!inMST[next_v]) {
                pq.push({next_weight, {v, next_v}});
            }
        }
    }
    
    // 打印结果
    cout << "--- Prim 算法结果 ---" << endl;
    // 顺便找回一下各边的权值用于打印
    for (const auto& e : mst_edges) {
        int u = e.first, v = e.second;
        int w = 0;
        for (auto& neighbor : adj[u]) {
            if (neighbor.first == v) { w = neighbor.second; break; }
        }
        cout << "边: " << u << " - " << v << " \t权值: " << w << endl;
    }
    cout << "最小生成树总权值: " << mst_weight << endl;
}
```
## 求解最短路径

求解最短路径可以通过Dijkstra算法和Floyd算法实现，算法的思想参考离散数学的部分，可以求两个结点之间的最短距离。Floyd算法可以批量的求两个结点之间的最短距离

```cpp
#include <vector>
#include <queue>
#include <utility>

// 定义无穷大，取 1e9 以避免后续加法运算导致 int 溢出
constexpr int INF = 1e9;

// 边结构：{目标顶点, 边的权重}
using Edge = std::pair<int, int>;

/**
 * @brief Dijkstra 算法：计算从起点到其余所有顶点的最短路径（仅适用于非负权图）
 *
 * @param n 顶点总数（顶点编号为 0 到 n-1）
 * @param adj 图的邻接表表示，adj[u] 存储所有从 u 出发的边 {v, weight}
 * @param start 起点编号
 * @return std::vector<int> 从 start 到各顶点的最短距离（不可达则为 INF）
 */
std::vector<int> dijkstra(int n, const std::vector<std::vector<Edge>>& adj, int start) {
    std::vector<int> dist(n, INF);
    dist[start] = 0;

    // 最小堆（优先队列）：存储 {当前已知最短距离, 顶点编号}
    using State = std::pair<int, int>;
    std::priority_queue<State, std::vector<State>, std::greater<State>> pq;
    pq.push({0, start});

    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();

        // 若出队的距离大于已记录的最短距离，说明是旧的冗余状态，直接跳过
        if (d > dist[u]) {
            continue;
        }

        // 遍历邻居顶点并进行松弛操作
        for (const auto& [v, weight] : adj[u]) {
            if (dist[u] + weight < dist[v]) {
                dist[v] = dist[u] + weight;
                pq.push({dist[v], v});
            }
        }
    }

    return dist;
}

/**
 * @brief Floyd-Warshall 算法：计算图中任意两点之间的最短路径（支持负权边，但不能有负权环）
 *
 * @param n 顶点总数（顶点编号为 0 到 n-1）
 * @param dist 图的邻接矩阵（按值传递，不破坏原矩阵）：
 *             dist[i][i] 应初始化为 0，无直接相连的边应初始化为 INF
 * @return std::vector<std::vector<int>> 包含所有顶点对之间最短距离的二维矩阵
 */
std::vector<std::vector<int>> floydWarshall(int n, std::vector<std::vector<int>> dist) {
    // k 为中间节点，必须放在最外层循环
    for (int k = 0; k < n; ++k) {
        for (int i = 0; i < n; ++i) {
            // 若 i 到 k 不可达，无需尝试经过 k 跳转
            if (dist[i][k] == INF) continue;

            for (int j = 0; j < n; ++j) {
                if (dist[k][j] == INF) continue;

                // 状态转移：尝试通过 k 缩短 i 到 j 的距离
                if (dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }

    return dist;
}
```
## 判断环的有无

可以通过DFS遍历来解决这一判断，如果我们在遍历的过程中，遇到一个结点是已经被遍历过的，就说明一定存在环，导致可以回来
# 拓扑排序

X上有关系R，对于集合X上的一个序列 $A=a_1,a_2,...,a_n$，如果当 $1\le i < j \le n$ 时，$(a_i,a_j)\in R$，我们就说A相对于R是拓扑有序的

拓扑排序就是由某个集合上的偏序关系得到此集合上的一个全序关系的过程

要实现拓扑排序，就需要从源点出发，将当前结点放入序列，然后去除其出边，然后继续不断寻找入度为0的结点，如果到结束时，剩下了一些有前驱的结点，就说明存在环。如果图中没有环，那么结点退出DFS排序的逆序就天然地是拓扑排序序列
# 关键路径

AOE网是一种图，可以用于描述工程，其用结点表示时间，弧表示活动，弧度赋权，权表示活动的时间。源点是其起点，入度为0；汇点是其终点，出度为0

这时候我们定义，事件的最早发生时间 $ve(i)$，就是源点到结点i的最长路径长度 *(含权)*，其决定了所有以 $v_i$ 为始点的边所代表的活动 $a_j$ 最早开始的时间 $e(j)$，$e(j)=ve(i)$，要求这一值，只需对于所有的边 $(v_i,v_j)$ 进行 $ve(j)=min(ve(j),ve(i)+dur(v_i,v_j))$ 即可

关键路径就是从源点到汇点地最长路径，可能有多条

边所代表的活动有最迟开始时间 $l(j)$，其表示，如果活动结束时在这个边的终点所代表的事件恰开始，那么这个边的活动的开始时间就是 $l(j)$，也就是在不影响后序活动的情况下最迟能拖多久，如果这个活动具有长度 $dur(j)$，终点 $vl(k)$，那么 $l(j)=vl(k)-dur(j)$

其中 $l(j)=e(j)$ 的活动，我们称为关键活动，关键活动处于关键路径上，关键路径是从源点到汇点的最长路径，缩短工程的工期，核心在于缩短所有关键路径的长度

事件也具有最迟发生时间 $vl(i)$，要求时间的这一值，就需要从汇点开始，对于每个结点 $i$ 递归地 *(或运用栈)* 找到其所有前驱 $j$，然后令其最迟发生时间为 $min(vl(j), vl(i)-dur(v_j,v_i))$

求拓扑排序与求关键路径的算法是一体的

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>

using namespace std;

// 边结构体：表示有向赋权边
struct Edge {
    int to;      // 终点
    int weight;  // 权值（活动持续时间）
};

/**
 * @brief 求解有向赋权图的关键路径
 * @param n 顶点数量（编号 0 到 n-1）
 * @param adj 邻接表
 * @return 若存在环返回 false，否则返回 true 并输出关键活动
 */
bool criticalPath(int n, const vector<vector<Edge>>& adj) {
    vector<int> inDegree(n, 0);
    // 1. 统计所有顶点的入度
    for (int u = 0; u < n; ++u) {
        for (const auto& edge : adj[u]) {
            inDegree[edge.to]++;
        }
    }

    // 2. 拓扑排序初始化
    queue<int> q;
    for (int i = 0; i < n; ++i) {
        if (inDegree[i] == 0) {
            q.push(i);
        }
    }

    vector<int> topoOrder;      // 存储拓扑序列
    vector<int> ve(n, 0);       // ve[i]: 事件(顶点)i的最早发生时间

    // 3. 执行 Kahn 拓扑排序，同时递推计算 ve
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        topoOrder.push_back(u);

        for (const auto& edge : adj[u]) {
            int v = edge.to;
            int w = edge.weight;
            // 更新后继顶点的最早发生时间
            ve[v] = max(ve[v], ve[u] + w);
            
            if (--inDegree[v] == 0) {
                q.push(v);
            }
        }
    }

    // 判断图中是否存在环
    if (topoOrder.size() != n) {
        cout << "图中存在环，无法求关键路径！" << endl;
        return false;
    }

    // 获取整个工程的最短完成时间（所有事件 ve 的最大值，兼容多汇点情况）
    int maxTime = *max_element(ve.begin(), ve.end());

    // 4. 逆拓扑序递推计算 vl（事件的最晚发生时间）
    vector<int> vl(n, maxTime);
    for (int i = n - 1; i >= 0; --i) {
        int u = topoOrder[i];
        for (const auto& edge : adj[u]) {
            int v = edge.to;
            int w = edge.weight;
            // 更新当前顶点的最晚发生时间
            vl[u] = min(vl[u], vl[v] - w);
        }
    }

    // 5. 计算每条边(活动)的 e 和 l，找出所有关键活动
    cout << "工程总工期为: " << maxTime << endl;
    cout << "关键活动（关键路径上的边）如下：" << endl;
    for (int u = 0; u < n; ++u) {
        for (const auto& edge : adj[u]) {
            int v = edge.to;
            int w = edge.weight;
            int e = ve[u];       // 活动的最早开始时间
            int l = vl[v] - w;   // 活动的最晚开始时间

            // 若时间余量为 0 (e == l)，则为关键活动
            if (e == l) {
                cout << u << " -> " << v << " (权值: " << w << ")" << endl;
            }
        }
    }

    return true;
}
```
